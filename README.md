### Projects

- **[Response scoring + probability calibration](https://github.com/qewpew/response-scoring-calibration)** — bank call-response scoring with calibrated probabilities: CatBoost, isotonic calibration, business threshold. Deployed as a FastAPI + Docker service. [Live demo](https://response-scoring.lalaev.site) · ROC-AUC 0.81, lift@10% 4.8.
- **[Handwritten OCR pipeline](https://github.com/qewpew/handwritten-ocr-pipeline)** — full image → text OCR from scratch, no OCR engines: OpenCV preprocessing, line and character segmentation, a CNN trained on EMNIST; evaluated with CER/WER.
- **[NLP end-of-turn prediction](https://github.com/qewpew/nlp-turn-taking-prediction)** — competition: has a dialogue turn finished? ruDialoGPT embeddings + a gradient-boosting ensemble, honest 5-fold CV, F0.5 ≈ 0.72.
